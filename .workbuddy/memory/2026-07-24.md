## 20:38 — 修复 Rust 构建错误（4 error + 1 warning）

**环境变化**：本会话 Bash/PowerShell shell 已恢复正常（与早间记录的"shell 不可用"不同），可直接跑 cargo。

**病根 + 修复（3 个文件）**：
1. `src-tauri/src/timer.rs` — `app.state::<AppState>()` 报 E0599（找不到 `state` 方法）。根因：`state()` 来自 `tauri::Manager` trait 未导入。修复：`use tauri::AppHandle;` → `use tauri::{AppHandle, Manager};`。同时发现 E0716 隐藏错误（前 3 个错误挡住了）：`app.state::<AppState>().timer.notify.notified()` 的临时 `State` 在 await 期间被 drop。修复：在循环体先 `let state = app.state::<AppState>();`，clone 出 owned `Arc<Notify>`，让 `notified()` future 借用 owned 值。
2. `src-tauri/src/commands.rs` — warning: unused import `Manager`。修复：移除未用导入，`use tauri::{AppHandle, Manager};` → `use tauri::AppHandle;`（该文件 state 经参数注入，autolaunch 来自 `ManagerExt` 不是 `Manager`）。
3. `src-tauri/src/shake.rs` — E0597 `mon` 生命周期不足。根因：`MonitorHandle::position()` 返回 `&PhysicalPosition<i32>`（借用），`base` 是引用，被 move 进 `std::thread::spawn` 的 `'static` 闭包。修复：`let base = mon.position();` → `let base = *mon.position();` 解引用为 owned（`PhysicalPosition<i32>` 是 `Copy`）。

**验证**：`cargo check` 通过，2.00s，零 error 零 warning。

**可复用知识点（Rust/Tauri 2 常见坑）**：
- trait 方法必须把 trait 引入作用域才能调用（实现 ≠ 可用）。
- Tauri 2 getter 常返回引用（如 `MonitorHandle::position`），跨线程/await 边界需解引用成 owned 值。
- `tokio::select!` 分支的 future 跨 await，不能借用临时 `State`；先 clone 出 owned `Arc` 再 await。

## 20:48 — 新增 overlay 关闭模式 + shake 异步化

**功能**：
1. `shake.rs` 把 `std::thread::spawn` 换成 `tauri::async_runtime::spawn` + `tokio::time::sleep`，不再独占 OS 线程跑 800ms 抖动动画。
2. overlay 关闭模式（Auto/Manual）：Auto 可配置显示时长（2-30 秒，默认 5），到时自动隐藏；Manual 不自动消失，渲染"我知道了"关闭按钮，点击调 `close_overlay` 命令隐藏。
3. Settings 新增 segmented control 切换模式 + 时长输入；Overlay 据 `shake-start` 事件 payload 的 `manual` 字段决定是否渲染关闭按钮。

**改动文件**：
- `config.rs`：加 `OverlayMode` enum（serde lowercase "auto"/"manual"）、`overlay_mode`/`overlay_duration_sec` 字段、load/save 兼容旧 store。
- `commands.rs`：ConfigDto 加字段、set_config 加可选参数、新增 `close_overlay`。
- `lib.rs`：注册 `close_overlay`。
- `shake.rs`：异步化；`shake-start` payload 改为 `{intensity, manual}`。
- `Overlay.tsx` / `Settings.tsx` / `styles.css`：UI 配套。

**再次踩坑（同会话内）**：
- `app.state::<AppState>()` 临时值借用问题在 shake.rs 又出现（`.config.lock()` 借用临时 State → E0716）。这是项目里反复出现的模式，根因是 `app.state()` 返回临时 `State`，链式调用 `.field.lock()` 会让 guard 借用临时值。**统一解法：先 `let state = app.state::<AppState>();` 绑定，再访问字段。**
- `store.get()` 返回 owned `JsonValue`，`v.as_str()` 借用 owned 值在闭包返回时悬垂（E0515）。解法：用 `serde_json::from_value::<T>(v)` 直接反序列化，复用类型的 serde。

**验证**：cargo check 2.27s 通过，tsc --noEmit 通过，零 error 零 warning。

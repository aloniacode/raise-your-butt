## 用户做出的关键选择
- 屏幕抖动方式：**全屏覆盖层抖动**（不动真实窗口）
- 提醒触发：抖动 + 系统通知
- 主菜单：弹出设置窗口（非原生托盘菜单）
- 前端栈：React + TS

## 技术决策
- 抖动实现：使用 Tauri 原生 `WebviewWindow::set_position`（不用 Win32 SetWindowPos FFI），避免本会话无法验证 FFI 兼容性。仍属"Rust 实现抖动"，并叠加前端 CSS 抖动 + 全屏覆盖层半透明遮罩。
- 定时器：tokio `select!` + `Notify`，改间隔立即重置倒计时（在 commands.rs 加了 interval_changed 判断，避免仅调强度时反复重置）。
- 关闭窗口：拦截 `CloseRequested` -> `prevent_close` + `hide`，进程继续在托盘运行。
- 单一 SPA 按 window label (`settings` / `overlay`) 分支，免去多 Vite entry。

## 已知阻塞 / 用户需自行操作
- **当前会话 shell (Bash & PowerShell) 不可用**：每条命令都 exit 1 无输出。即便禁沙盒也一样。所以 `create-tauri-app / pnpm install / cargo build / tauri dev` 全部需要用户在 terminal 里手动跑。

  1. `pnpm install`
